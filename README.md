# Dynamic Cat Wallpaper

A time-of-day wallpaper changer for Windows 10, inspired by Cinnamon's dynamic wallpapers. It picks a wallpaper based on the current time and crossfades between images instead of snapping from one to the next.

Plain PowerShell and Task Scheduler. No tray app, no background service, no dependencies.

## Features

- Different wallpaper for each part of the day, set in a simple `config.json`
- Smooth crossfade between images (default 30 minutes), built with `System.Drawing`
- Runs silently in the background: checks every 5 minutes and at logon
- Catches up after sleep or shutdown, so the right wallpaper shows when you're back
- Preview any time of day without waiting
- Clean uninstall

## Install

1. Download the latest zip from [Releases](../../releases) (or clone this repo) and put the folder somewhere permanent, e.g. `C:\Tools\DynamicCatWallpaper`.
2. Double-click `install.bat`.

That's it. The scheduled task runs the scripts from this folder, so if you move it, run `install.bat` again.

If `install.bat` reports that it couldn't add the logon trigger, right-click it and choose **Run as administrator**. Without that trigger the wallpaper still updates, but up to 5 minutes after you sign in.

## Configure

Edit `config.json`:

```json
{
  "transitionMinutes": 30,
  "fillMode": "Fill",
  "schedule": [
    { "time": "05:30", "image": "Cats_in_misty_forest.jpg" },
    { "time": "07:00", "image": "Cats_in_morning_forest.jpg" }
  ]
}
```

| Setting | Meaning |
|---|---|
| `schedule[].time` | When this image starts, 24-hour `HH:mm` |
| `schedule[].image` | File name inside the `wallpapers/` folder |
| `transitionMinutes` | How long the fade from the previous image takes. Use `0` for instant switching |
| `fillMode` | `Fill`, `Fit`, `Stretch`, `Center`, `Tile` or `Span` |

Entries can be in any order. The last entry of the day wraps around past midnight to the first one. Changes apply on the next 5-minute check.

### Default schedule

| Time | Wallpaper |
|---|---|
| 05:30 | misty |
| 07:00 | morning |
| 10:30 | peaceful |
| 15:30 | golden |
| 18:30 | evening |
| 20:00 | enchanted |
| 22:30 | moonlit |

## Preview

Open PowerShell in the project folder:

```powershell
.\Set-Wallpaper.ps1 -At 18:45 -DryRun   # print what it would show, change nothing
.\Set-Wallpaper.ps1 -At 18:45           # actually apply the 18:45 look
.\Set-Wallpaper.ps1                     # back to the real time
.\Set-Wallpaper.ps1 -Force              # re-apply even if nothing changed
```

## How it works

1. Reads `config.json` and finds the most recent schedule entry whose start time has passed.
2. If you're within `transitionMinutes` of that start time, it blends the previous and current images at the matching percentage (in 5% steps) and saves the result to `%LOCALAPPDATA%\CatWallpaper`.
3. Sets the wallpaper through the Windows `SystemParametersInfo` API and records what it set, so unchanged runs do nothing.

Windows has no native wallpaper fade, so each transition appears as a series of small steps rather than a continuous animation.

## Uninstall

Double-click `uninstall.bat`. It removes the scheduled task and the cache folder. Your current wallpaper stays as it is.

## Using your own images

Drop your images into `wallpapers/` and list them in `config.json`. Any size works, and the blend uses the size of the earlier image in each pair, so images with matching dimensions fade best. Higher-resolution images look sharper on larger screens.
